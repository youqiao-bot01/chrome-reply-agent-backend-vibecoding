## 1. pytest 失败用例说明

**用例**: `test_refine_downgrades_false_strong_intent`

| 项 | 内容 |
|----|------|
| 输入 | 关键词已判为 `interest`；达人消息 `Interested!`；**context 为空** |
| 期望 | `refine_toolant_intent` 降级为 `GEN`（无 pitch 的裸 interested 不算强意向） |
| 实际 | 保持 `interest` 不变 |

**根因**（`toolant_intent.py` 249–260 行）：

降级为 `GEN` 的条件是：

```python
if _context_has_b_tier_sample_pitch(context_text) and not strong:
    return GEN
return result  # 空 context 走这里，保留 interest
```

即：**仅当上下文里已有「1样2视频」pitch、但达人未明确确认时**才降级。  
空 context 时 `_context_has_b_tier_sample_pitch("")` 为 False，函数直接 `return result`，不会降级。

**与同文件其他测试的关系**：

- `test_bare_interested_without_pitch_not_strong_intent` 走完整 `classify_user_message` 流水线，可能经其他规则得到 `GEN`/`ok`，故通过。
- 本用例 **单独调用** `refine_toolant_intent`，暴露 refine 层逻辑缺口。

**建议修复**（Phase 3）：在 `not strong` 且裸 accept、且 **无** two-video pitch 时亦降级为 `GEN`；或更新测试以匹配「仅 pitch 后未确认才降级」的产品定义。
