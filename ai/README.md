# AI 思考部分

> AI 输入与思考文档 **只在本目录**；代码说明见 `[code/README.md](../code/README.md)`；方案与 §0 强制规则见 `[PLAN.md](../PLAN.md)`。

## 协作流程

1. 阅读 `PLAN.md` **§0 实施规则** 与目标 Phase 章节
2. 在 `artifacts/` 记录分析 / 决策 / 检验
3. 更新 `PLAN.md` 版本记录
4. 再改 `code/`（代码不得反向依赖本目录）

**长任务 / 卡住**：执行或等待超过预期时，须按 `PLAN.md` **§0.5** 在前台说明原因并请求授权后再做检查（读终端、跑诊断命令等）。

**大任务**：Phase 级工作须按 **§0.6** 拆成多 agent——各 agent 先自规划、目录独占、互不干扰并发；结束后再集成收口。

**分步同意**：§5 每个 Phase 须按 **§0.7** 先提交思考 + 执行清单 + 检验标准，**用户同意后再执行**。

## 目录


| 路径                   | 用途                        |
| -------------------- | ------------------------- |
| `inputs/data/`       | 业务数据索引（实际文件在 `rag_data/`） |
| `inputs/experience/` | if-then 专家经验、业务规则摘要       |
| `inputs/references/` | 外部参考、平台文档摘录               |
| `artifacts/`         | 思考过程产物（分析、对比、检验报告）        |


方案定稿写入根目录 `**PLAN.md`**，不在此维护多份方案文件。

## 与代码的边界

- 本目录内容 **不参与** Python 打包与运行。
- 专家规则的可执行形式在 `code/assets/schema/` 与 `code/src/`；本目录仅保留人类可读的摘要与决策说明。
